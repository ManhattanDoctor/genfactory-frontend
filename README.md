# Genfactory frontend

Новая студия изображений и видео на `gnosis-backend`. Интерфейс использует бренд Genfactory, тёмные поверхности и лаймовый акцент исходного сайта; сценарии построены вокруг создания и работы с результатом.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite проксирует `/api` в `GNOSIS_API_TARGET` (по умолчанию `http://127.0.0.1:3015`). Указывайте именно API gnosis, не старый `/api/studio` Genfactory. Для локального OAuth в Keycloak должен быть разрешён точный redirect URI `http://127.0.0.1:5173/auth/callback` (или `http://localhost:5173/auth/callback`, если используется localhost).

В режиме разработки диалог входа также позволяет подключить существующий токен gnosis. Это поле отсутствует в production-сборке. Токен не передаётся в URL и не сохраняется в репозитории.

## Что работает

- Вход через публичную конфигурацию gnosis и Keycloak, чтение аккаунта и балансов.
- Каталог реальных моделей, формы из JSON Schema, проверка условных ограничений через Ajv.
- Text-to-image, image-to-image для моделей с соответствующим полем в схеме; PNG/JPEG/WebP-референсы.
- Text-to-video и первый/последний кадр, если каталог модели содержит `frameImages`.
- Выполнение `/api/task`, автоматическое сохранение изображений через `/api/fileBuffer`, получение готового видео по `fileId`.
- Библиотека файлов gnosis с пагинацией и предпросмотром; изображение из библиотеки можно использовать как референс.
- Локальная история последних 100 запусков на пользователя. Файлы хранятся на сервере; история запуска пока ограничена этим браузером.
- Состояния неопределённого результата и ошибки сохранения без автоматического повторения платной генерации.

Настоящие модели не вызываются тестами. Визуальные примеры на главной — материалы существующего Genfactory, а не якобы созданные пользователем результаты. Промпты рядом с ними являются стартовыми идеями, не восстановленными исходными промптами этих изображений.

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Playwright перехватывает API: генерации и загрузки в S3 в этих тестах не выполняются. Снимки экрана и трассы сохраняются в игнорируемую папку `test-results`.

## Границы текущей версии

Это рабочий интеграционный frontend, не готовая к публичной эксплуатации платёжная платформа. До запуска требуется серверный журнал генераций с идемпотентностью, восстановление задач и полноценный отзыв сессий. Текущий `/api/task` держит соединение до результата; обновление страницы не гарантирует восстановление результата обычной задачи. Приложение показывает неопределённый исход и не пересоздаёт задачу автоматически.

В текущем API нет операции онлайн-пополнения и предварительного расчёта цены. Интерфейс не обещает несуществующий checkout, бесплатные генерации, фиксированную цену или возврат за отмену. Стоимости показываются в валюте, возвращённой gnosis.

Архитектура и следующие серверные изменения: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/BACKEND-CONTRACT.md](docs/BACKEND-CONTRACT.md). Production-развёртывание: [docs/OPERATIONS.md](docs/OPERATIONS.md).
