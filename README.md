# Genfactory frontend

Творческая AI-студия для обсуждения идей, подготовки промптов, сценариев, изображений и видео на беседах и универсальных инструментах gnosis. Аккаунты, балансы, выполнение, файлы и история принадлежат gnosis.

## Запуск

Node.js 20.19+ или 22.12+.

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite проксирует `/api` в `GNOSIS_API_TARGET` (по умолчанию `http://127.0.0.1:3015`). В Keycloak разрешите точный redirect URI `http://127.0.0.1:5173/auth/callback` и/или `http://localhost:5173/auth/callback`. В development доступен вход существующим SID gnosis; в production это поле отсутствует.

## Что работает

- Аккаунт и балансы gnosis, Keycloak. Вход сохраняется между вкладками и перезапусками браузера для одного origin; выход синхронизируется между вкладками.
- Настоящий каталог моделей и параметры по JSON Schema.
- Новая работа в медиа-редакторе — беседа с универсальными `IMAGE` и `VIDEO`; конкретная модель и параметры передаются в настройках инструмента.
- Следующий запрос продолжает ту же беседу. «Новая работа» создаёт отдельную.
- PNG/JPEG/WebP-референсы прикрепляются к сообщению по file IDs.
- Изображение можно изменить или использовать для видео в той же беседе.
- Результаты сохраняются инструментами на backend; frontend читает сообщения и файлы.
- Прогресс IMAGE/VIDEO и ошибки инструментов через существующие socket-события с HTTP-восстановлением после перезагрузки.
- Серверная история собственных бесед, пагинация, продолжение с другого устройства.
- После перезагрузки сохранённые сообщения и статус восстанавливаются с сервера. Повторный платный POST автоматически не отправляется.
- AI-чат, Generate Prompt с выбором языка/назначения/аспектов и сценарист на существующих беседах. Новые текстовые беседы по умолчанию не подключают инструменты генерации.
- Выбор инструментов из серверного каталога, включая универсальные инструменты, доступные MCP и графы; явное сохранение подключений существующей беседы.
- Перенос готового ответа и референсов в редакторы изображений и видео, копирование текста.
- Галерея из восьми стартовых шаблонов, собственные шаблоны с моделью и параметрами, избранное; Nano Banana/Seedance как отфильтрованные представления живого каталога.
- Настройки съёмки и правила бренда с версиями. Правила применяются по явному включению; параметры съёмки формируют пожелания в тексте запроса.
- Выбор материала из библиотеки внутри редактора; документы и аудио в AI-студии требуют соответствующего инструмента. TXT/Markdown можно включить в текст запроса. Видео для Generate Prompt разбирается локально на три кадра, без аудиоанализа.
- История: переименование на сервере, поиск на странице, локальные избранное и архив, серверная выборка выполняющихся работ.
- Библиотека изображений, видео, документов и аудио, предпросмотр, адаптивный интерфейс.

Шаблоны, избранное, архив и версии правил бренда хранятся в localStorage отдельно для каждого аккаунта и не синхронизируются между устройствами. Архив скрывает работу только в этом браузере. Переименование и настройки инструментов сохраняются в gnosis. При передаче ответа в генерацию используется та же беседа, если нужный инструмент уже подключён; иначе создаётся новая работа с выбранным текстом и референсами.

Прямые POST `/task`, клиентское сохранение через `/fileBuffer` и браузерный журнал генераций удалены из потока. Старый локальный журнал автоматически не переносится; ранее сохранённые в gnosis файлы остаются в библиотеке.

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты подменяют API и не вызывают платные модели. Они проверяют создание/продолжение беседы, настройки инструментов, серверную историю, переход image-to-video, восстановление после потери ответа и изоляцию аккаунта. Реальная цепочка image → edit → video также проверена отдельно на техническом аккаунте; результаты и финансовая сверка описаны в docs/OPERATIONS.md.

Стоимость сообщения API не возвращает: UI показывает баланс, но не выдумывает цену результата. Работа ассистента и инструментов оплачивается gnosis. Выбранные параметры инструментов — предпочтения; строгую фиксацию аргументов и единственный вызов агента текущий контракт не гарантирует.

Архитектура: [ARCHITECTURE.md](docs/ARCHITECTURE.md). Точные контракты и оставшиеся ограничения: [BACKEND-CONTRACT.md](docs/BACKEND-CONTRACT.md). Развёртывание: [OPERATIONS.md](docs/OPERATIONS.md).

Локальные удобства рабочего пространства: черновики с восстановлением, поиск/избранные модели, вставка и перетаскивание референсов, перестановка вложений, просмотр и сравнение результатов, скачивание, панель активных работ. На странице «Правила бренда» доступен экспорт/импорт локальных настроек JSON. Черновики и настройки привязаны к аккаунту в текущем браузере; межустройственная синхронизация и фоновые уведомления не реализованы.

Планы переноса временных клиентских решений в gnosis ведутся в [списке доработок backend](docs/BACKEND-BACKLOG.md). Это предложения для отдельного обсуждения; текущие frontend-доработки не меняют серверный API.

CI/CD: [сборка, публикация образа, SSH-деплой и откат](docs/CICD.md).

Проверки входа и выхода: `npm run test:auth` (Chromium) и
`npm run test:auth:webkit` (WebKit; предварительно `npx playwright install webkit`).
Провайдер SSO и API в этих тестах подменяются: реальные аккаунты не используются.

План переноса интерфейса по прототипу и документу заказчика: [PROTOTYPE-MIGRATION.md](docs/PROTOTYPE-MIGRATION.md).
