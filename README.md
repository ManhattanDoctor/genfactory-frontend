# Genfactory frontend

Творческая студия изображений и видео на беседах и универсальных инструментах gnosis. Аккаунты, балансы, выполнение, файлы и история принадлежат gnosis.

## Запуск

Node.js 20.19+ или 22.12+.

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite проксирует `/api` в `GNOSIS_API_TARGET` (по умолчанию `http://127.0.0.1:3015`). В Keycloak разрешите точный redirect URI `http://127.0.0.1:5173/auth/callback` и/или `http://localhost:5173/auth/callback`. В development доступен вход существующим SID gnosis; в production это поле отсутствует.

## Что работает

- Аккаунт и балансы gnosis, Keycloak.
- Настоящий каталог моделей и параметры по JSON Schema.
- Новая работа — беседа с универсальными `IMAGE` и `VIDEO`; конкретная модель и параметры передаются в настройках инструмента.
- Следующий запрос продолжает ту же беседу. «Новая работа» создаёт отдельную.
- PNG/JPEG/WebP-референсы прикрепляются к сообщению по file IDs.
- Изображение можно изменить или использовать для видео в той же беседе.
- Результаты сохраняются инструментами на backend; frontend читает сообщения и файлы.
- Серверная история собственных бесед, пагинация, продолжение с другого устройства.
- После перезагрузки сохранённые сообщения и статус восстанавливаются с сервера. Повторный платный POST автоматически не отправляется.
- Библиотека файлов, предпросмотр, адаптивный интерфейс.

Прямые `/task`, клиентское сохранение через `/fileBuffer` и браузерный журнал генераций удалены из потока. Старый локальный журнал автоматически не переносится; ранее сохранённые в gnosis файлы остаются в библиотеке.

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты подменяют API и не вызывают платные модели. Они проверяют создание/продолжение беседы, настройки инструментов, серверную историю, переход image-to-video, восстановление после потери ответа и изоляцию аккаунта. Реальные платные генерации требуют отдельной end-to-end проверки.

Стоимость сообщения API не возвращает: UI показывает баланс, но не выдумывает цену результата. Работа ассистента и инструментов оплачивается gnosis. Выбранные параметры инструментов — предпочтения; строгую фиксацию аргументов и единственный вызов агента текущий контракт не гарантирует.
